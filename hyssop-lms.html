Project Overview

Built for East African Finance

Hyssop LMS is a comprehensive loan management platform engineered for the East African financial landscape. It handles the full loan lifecycle — from investor fund management through loan origination, CRB credit checks, disbursement, collateral tracking, and repayment — all within a secure, auditable, and event-driven architecture.


Designed as a modular monolith following Domain-Driven Design principles, every financial transaction is immutable, every mutation is audit-logged, and the entire system is built to scale toward microservices without architectural debt.

Core Modules

Everything Built In

Eight production-ready modules covering the complete loan lifecycle — from investor capital through final clearance.

💰
INVESTOR FUNDS
Track capital contributions, calculate returns, manage withdrawals, and generate automated investor reports with real-time portfolio visibility.
Deposit → Investment → Loan → Returns → Withdrawal
📋
LOAN ORIGINATION
Full loan application, multi-step approval workflow, and disbursement management with role-based authorization and full audit trail.
Apply → Review → Approve → Disburse
🏠
COLLATERAL
Register and track physical or financial collateral linked to loans. Includes admin verification, valuation recording, and automated status alerts.
Submit → Verify → Valuate → Link to Loan
⚡
REPAYMENT ENGINE
Monitors payments in real-time, calculates principal and interest components, tracks outstanding balances, and handles partial payments and overdue scenarios.
Schedule → Collect → Allocate → Reconcile
🛡️
CRB INTEGRATION
Live integration with Kenya's Credit Reference Bureau APIs. Automated credit score checks before loan approval, with full response logging and compliance records.
Request → CRB API → Score → Decision
📊
REPORTING & ANALYTICS
Role-specific dashboards for admin, investors, and borrowers. Real-time financial metrics, default rate tracking, ROI calculations, and exportable reports.
Aggregate → Visualize → Export
🔔
ALERTS & NOTIFICATIONS
Event-driven SMS and email notifications powered by Redis queues. Automated alerts for approvals, due payments, overdue loans, and suspicious activity.
Event → Queue → SMS/Email
📜
CLEARANCE CERTIFICATES
Automated generation of loan clearance certificates upon full repayment. Digitally signed, timestamped, and stored in the immutable audit log.
Repaid → Verify → Generate → Deliver

Security & Compliance

Production Hardened

Every layer secured. Every mutation logged. Built to meet financial institution standards from day one.

🔐
Role-Based Access Control
Separate permissions for Admin, Loan Officer, Investor, Borrower, and Auditor. Zero privilege creep.
🔒
Data Encryption
Encryption at rest for sensitive fields (IDs, balances). HTTPS/TLS in transit. Bcrypt/Argon2 password hashing.
📋
Immutable Audit Logs
Every financial mutation writes an append-only audit record. Before/after state captured in JSONB with IP and timestamp.
🛡️
API Security
OAuth2/JWT authentication, input validation, rate limiting, WAF at the gateway layer. Regulatory-compliant endpoints.
// Security Request Flow

incoming_request
→ JWT Authentication
→ RBAC Policy Check
→ Input Validation
→ DB Transaction
→ Audit Log Entry
→ Response

// Ledger Rules
ledger_entries {
debit: NUMERIC(18,2) ≥ 0
credit: NUMERIC(18,2) ≥ 0
policy: "INSERT ONLY"
rls: ENABLED
}

// Postgres Hardening
ROW_LEVEL_SECURITY: ON
CHECK(debit >= 0)
CHECK(credit >= 0)
INDEXES: loan_status, borrower_id, account_id
